# Bundled font

Noto Sans CJK JP Regular, from the Noto CJK project:
https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf

Copyright and licensing are preserved in OFL.txt (SIL Open Font License 1.1).
The common SVG renderer uses this font's glyph outlines; no system fonts are
required to render station names. The font is bundled unchanged.
